WILD THEME DOCUMENTS
18 Word documents with a theme built into the file. Send one to anyone: they see
the theme with nothing installed (no extension, no add-in, no AI).

Inside each file: theme colours and fonts, matching heading/quote styles, an
animated backdrop and a solid reading panel behind the text on every page
(locked so they can't be clicked away), and file properties naming the theme
(File > Info > Properties). Word's own theme buttons are locked for the file.

Word desktop: backdrop animates.  Word for the web: still picture.
To change or remove the theme, use the Wild Themes add-in or the browser
extension's "Save theme into a Word file" page. Pages are A4.
